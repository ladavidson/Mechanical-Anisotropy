This repository includes custom FIJI macro files and MATLAB m-files used in: Yang, J., Dong, Y., Jones, C. B., Wang, Y., Merino, C. V., Stuckenholz, C. and Davidson, L. A. (2026) 'Mechanical anisotropy and medio-apical force transmission shape cellular strain heterogeneity in epithelia', Development.
The original paper can be found at: 10.1242/dev.205417
The files are also deposited at Zenodo: 10.5281/zenodo.23303024
